# Pet-Supplies-Vibe-Search
An advanced, end-to-end e-commerce search engine that combines traditional keyword matching (BM25) with semantic vector search (ChromaDB), all wrapped in a Retrieval-Augmented Generation (RAG) web application.
🚀 The Core Problem
Traditional e-commerce search engines rely on exact keyword matches. If a user searches for "indestructible toy", a keyword engine will miss products labeled as "durable heavy-duty chew". Conversely, pure semantic AI search might understand the "vibe" but miss exact brand names like "KONG".The Solution: This project implements a Weighted Hybrid Search architecture that runs both engines simultaneously and mathematically merges their results, passing the final, highly-accurate context to an LLM to generate a personalized shopping recommendation.
✨ Key Features
Semantic Vector Search: Uses all-mpnet-base-v2 embeddings to understand the contextual "vibe" and natural language of a user's query.Lexical Keyword Search: Uses rank_bm25 (TF-IDF) to ensure exact brand names, measurements, and specific vocabulary are never missed.Tunable Alpha Dial: A custom weighting algorithm that allows the user to dynamically adjust the balance between Semantic Search ($\alpha=1.0$) and Keyword Search ($\alpha=0.0$).Reciprocal Rank Fusion (RRF): Merges the results of both engines using the industry-standard RRF algorithm:$$RRF(d) = \frac{1}{k + rank_{vector}(d)} + \frac{1}{k + rank_{keyword}(d)}$$RAG AI Assistant: Feeds the top search results into the Google Gemini API to generate a conversational, highly relevant product recommendation based on real reviews and product details.Interactive UI: A clean, lightning-fast frontend built entirely in Python using Streamlit.
