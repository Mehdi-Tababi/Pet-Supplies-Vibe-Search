# Pet-Supplies-Vibe-Search
Pet Supplies Vibe Search is an AI-powered e-commerce search engine that combines traditional keyword matching with semantic vector search. Traditional search engines often miss relevant products because they rely strictly on exact keyword matches, while pure AI searches can sometimes miss specific brand names. This project solves that problem by implementing a Weighted Hybrid Search architecture. It runs a lexical BM25 keyword engine alongside a ChromaDB semantic vector database, merging their results using a tunable Reciprocal Rank Fusion algorithm. The system is wrapped in a Retrieval-Augmented Generation web application built with Streamlit. When a user searches for a product, the application retrieves the best mathematical matches from the database and feeds them into the Google Gemini API to generate a personalized, conversational shopping recommendation based on real product details and reviews. To run this project locally, you need to clone the repository and install the required Python dependencies including streamlit, pandas, chromadb, sentence-transformers, rank-bm25, and google-generativeai. Ensure your cleaned product data CSV and the persistent ChromaDB folder are placed in the root directory. Finally, launch the application by typing streamlit run app.py in your terminal, open the provided local web address, and enter your Gemini API key to activate the AI assistant.
